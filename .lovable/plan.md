# Pixel-Faithful Reference Rebuild

## Goal
Rebuild the existing medical exam experience so the supplied image is the layout specification, not loose inspiration.

## Landing screen
- Keep the entire desktop experience within one framed, laptop-like viewport with no large empty area below the composition.
- Match the reference’s exact three-part balance: large exam message on the left, dominant concentric exam control in the center, and the short preparation statement on the right.
- Recreate the centered top motto, compact medical brand, profile icon, dark emergency-room backdrop, coral ring glow, warm amber details, and thin technical line work.
- Position the short and long practice circles directly below the main exam control, connected by fine illuminated lines.
- Pin the four compact benefit items to a translucent bottom rail inside the framed screen.
- Use the reference wording and Norwegian labels where they appear in the supplied design.

## Mobile case screen
- Match the supplied phone composition directly: compact top bar, case progress with segmented line, title and specialty badge, patient summary panel, six vital-sign tiles, findings list, two collapsed sections, and paired bottom navigation buttons.
- Keep information dense and readable at the current 384px phone width without horizontal overflow.
- Preserve typed and voice responses in the working case flow, but place them after the reference-matched clinical summary so the visible first screen stays faithful.

## Visual fidelity
- Lock the palette to near-black plum, coral red, warm amber, muted cream, and a small green status accent.
- Use tighter typography, smaller supporting copy, thin borders, minimal corner rounding, and precise spacing matching the screenshot.
- Use the generated emergency-room image only as the background asset; the supplied screenshot remains reference-only.
- Restrict animation to the glowing exam rings, small pulse trace, and subtle entrance motion.

## Verification
- Compare screenshots side by side at desktop and 384px mobile sizes.
- Verify the landing composition fits the first viewport, the mobile case matches the visible reference hierarchy, and all controls still work.
- Check text wrapping, scrolling, horizontal overflow, runtime errors, and the final build status.
